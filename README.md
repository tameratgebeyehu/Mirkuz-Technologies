# Tamerat Gebeyehu – personal website

My personal website: the apps I've built, my book, my courses and how to contact me.

I'm a Grade 12 student in Dodola, Ethiopia. "Mirkuz Technologies" is the name I use to publish my apps; it is not a registered company.

## Run it

```bash
npm install
npm run dev
```

## Where to change things

- All text (projects, courses, school, awards): `src/data/portfolioData.js`
- Blog posts: `src/content/blog/*.md`
- Project screenshots: `public/projects/<project>/1.jpg, 2.jpg, ...`
- APK downloads: `public/apks/`

Rule for this site: only write things that are true today and that someone could check.
If something is not finished, call it "in progress".

Deployed on Vercel.
